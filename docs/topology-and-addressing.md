# Схема и адресация

Схема экзаменационной сети находится в [`../assets/topology.png`](../assets/topology.png).

## Основные узлы
- ISP — промежуточный маршрутизатор.
- HQ-RTR — маршрутизатор главного офиса.
- BR-RTR — маршрутизатор филиала.
- BR-FW — межсетевой экран филиала.
- HQ-SRV, HQ-CLI, BR-SRV — конечные устройства.

## Адресация, отмеченная на схеме
- ISP ↔ HQ-RTR: `172.16.1.1/28` ↔ `172.16.1.2/28` (в конфигурации HQ-RTR маска отличается).
- ISP ↔ BR-RTR: `172.16.2.1/28` ↔ `172.16.2.2/28`.
- HQ-SRV: `192.168.2.2/28`, шлюз `192.168.2.1`.
- HQ-CLI: `192.168.3.2/28`, шлюз `192.168.3.1`.
- GRE: `10.10.10.1/30` ↔ `10.10.10.2/30`.
- BR-RTR ↔ BR-FW: `172.16.3.1/30` ↔ `172.16.3.2/30`.
- BR-FW ↔ BR-SRV: `172.16.4.1/30` ↔ `172.16.4.2/30` 

## VLAN на HQ-RTR
- VLAN 100: сеть серверов `192.168.2.0/28`.
- VLAN 200: сеть клиентов `192.168.3.0/28`.
- VLAN 999: сеть управления, в исходной конфигурации `192.168.99.0/30`.

> Важно: README и конфигурации не скрывают расхождения между рисунком и исходными командами. Приоритет имеет официальная схема/условие вашего варианта.
